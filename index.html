01 / REQUERIMIENTOS MÍNIMOS

Navegador web de escritorio actualizado (Google Chrome, Microsoft Edge, Mozilla Firefox o Brave) con soporte para WebAssembly y WebGL 2.0 activado.

02 / RENDIMIENTO Y HARDWARE

Aceleración por hardware habilitada en el navegador, 4 GB de RAM libres y conexión estable para la descarga inicial del paquete de datos (30 MB).

03 / INSTRUCCIONES TÉCNICAS

Una vez cargada la barra de Unity, haz clic dentro del lienzo del juego para enfocar el teclado y presiona ENTER para despegar hacia Saturno.
